# STRIKE 5×5

Лёгкий браузерный онлайн-шутер с видом сверху. Режим 5 на 5 (синие против красных), три карты: Склад, Пустыня, Город.
Свободные места занимают боты. Когда заходит живой игрок, он заменяет бота. Матч идёт до 50 убийств или 5 минут, потом включается следующая карта.
Если на сервере уже 10 живых игроков, для следующих создаётся ещё одна комната.

Управление: WASD — движение, мышь — прицел, ЛКМ — стрельба, R — перезарядка, Tab — таблица счёта.

## Быстрый запуск со ссылкой (5 минут, со своего компьютера)

Нужен Node.js 18+.

```bash
npm install
npm start                 # сервер на http://localhost:3000
```

Чтобы друзья зашли из интернета, в соседнем окне терминала запусти туннель:

```bash
npx localtunnel --port 3000
# или, если установлен cloudflared:
cloudflared tunnel --url http://localhost:3000
```

Он выдаст публичную ссылку `https://....` — кидай её друзьям. Ссылка работает, пока открыты оба окна.
В локальной сети можно просто открыть `http://<IP-твоего-ПК>:3000`.

## Постоянная ссылка (бесплатно, Render.com)

1. Залей папку в репозиторий на GitHub.
2. На https://render.com: New → Web Service → выбери репозиторий.
3. Runtime: Node, Build Command: `npm install`, Start Command: `npm start`, Instance Type: Free.
4. После деплоя получишь ссылку вида `https://strike-5v5.onrender.com`.

На бесплатном тарифе сервер засыпает после 15 минут без посетителей, и первый вход занимает около минуты.
Подойдут и Railway, Fly.io или любой VPS: нужен только `npm start` и переменная `PORT`.

## Структура

- `server.js` — сервер (HTTP + WebSocket, 30 тиков/с, логика матча, боты)
- `public/shared.js` — карты, константы, коллизии (общие для сервера и клиента)
- `public/index.html` — клиент (canvas, интерфейс, предсказание движения)

Баланс (урон, скорострельность, лимит очков и т.д.) настраивается в `C` в `public/shared.js`.
Карты задаются левой половиной из 20 символов, правая отзеркаливается автоматически:
`#` — стена, `.` — пол, `A` — спавн.
