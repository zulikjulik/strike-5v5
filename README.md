# STRIKE 5×5 — 3D

Браузерный онлайн-шутер от первого лица (Three.js). Режим 5 на 5, свободные места занимают боты.

## Что есть
- 5 карт: Деревня, Пустыня, Город, Осень (листопад), Зима (снегопад). На каждой — двухэтажные дома с лестницами,
  трёхэтажная башня в центре, грузовики-спавны, деревья, ящики, бочки, мешки с песком, дым из труб.
- Серверы: быстрая игра, список серверов, создание своего (название, пароль, стартовая карта, боты вкл/выкл).
- Арсенал CS 1.6 (точность +25%), AWP пробивает насквозь, коллиматоры с красной точкой на AUG и SG 552,
  оптический прицел на AWP и Scout, хедшоты ×4, компенсация пинга.
- 5 кейсов: «Листопад», «Метель», «Дракон», «Галактика», «Кибер»; раскраски пяти редкостей, 7 видов ножей (штык-нож M9, бабочка, складной, медвежий, мачете, катана, керамбит), инвентарь, торговая площадка.
- Админ-панель: объявления, кик, смена карты, рестарт, боты, закрытие сервера, +деньги, открыть всё, бесплатные кейсы.

## Управление
WASD — ходьба, Shift — тихий шаг, Ctrl или C — присед, Пробел — прыжок, ЛКМ — огонь / удар ножом,
ПКМ — прицел, а с ножом — сильный удар, F — осмотр оружия, R — перезарядка, 1/2/3 — оружие, Tab — счёт, Esc — пауза.
Удар ножом в спину смертельный. Пока ты в игре, браузер спросит подтверждение перед закрытием вкладки (защита от Ctrl+W).

## Торговая площадка
Лоты и выплаты хранятся в `data/market.json` на сервере. На бесплатном тарифе Render файлы сбрасываются при
перезапуске сервера — тогда лоты пропадут. Для постоянного хранения нужен платный диск (Render Disk) или база данных.

## Деплой (Render.com)
Build Command: `npm install`, Start Command: `npm start`.
Пароль админа: Environment → добавить переменную `ADMIN_PASSWORD` со своим паролем.
(Если её нет, сервер придумает временный пароль и напишет его в логах при запуске.)

## Структура
- `server.js` — сервер: комнаты, матчи, физика, попадания, боты, админ-команды
- `public/shared.js` — карты (этажи, лестницы, башня, грузовики), физика, лучи, оружие, скины, раскраски, кейсы
- `public/index.html` — меню и интерфейс
- `public/game.js` — игра, меню, кейсы, инвентарь, админка, HUD
- `public/world.js` — 3D-мир, погода, модели оружия, ножей и персонажей
- `public/audio.js` — звуки и музыка
