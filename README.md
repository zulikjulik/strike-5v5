# STRIKE 5×5 — 3D

Браузерный онлайн-шутер от первого лица (Three.js). Режим 5 на 5, синие против красных, свободные места занимают боты.
Три карты с домами, в которые можно заходить: Деревня, Пустыня, Город. Через окна можно стрелять, на ящики можно запрыгивать.

Управление: WASD — движение, Пробел — прыжок, мышь — обзор, ЛКМ — огонь, ПКМ — прицел (AWP, Scout, AUG, SG 552),
1/2/3 или колесо — оружие, Q — прошлое оружие, R — перезарядка, Tab — счёт, Esc — пауза, M — музыка.

Попадание в голову ×4 урона. AWP убивает с одного выстрела и пробивает насквозь.
Деньги за убийства и победы тратятся в Арсенале (оружие CS 1.6) и на скины. Женские скины дороже — у них меньше хитбокс.
Деньги и покупки хранятся в браузере игрока (localStorage).

## Деплой (Render.com)

Build Command: `npm install`, Start Command: `npm start`. Three.js ставится через npm и раздаётся сервером.

## Структура

- `server.js` — сервер: матчи, физика, 3D-попадания, хедшоты, боты
- `public/shared.js` — карты, физика, лучи, оружие, скины (общие для сервера и клиента)
- `public/index.html` — меню, магазин, вёрстка
- `public/game.js` — игра: камера, оружие в руках, эффекты, HUD, радар, сеть
- `public/world.js` — 3D-мир: текстуры, дома, модели персонажей и оружия
- `public/render.js` — иконки оружия в магазине
- `public/audio.js` — звуки выстрелов и музыка

Карты задаются левой половиной из 20 символов в `shared.js` (правая отзеркаливается):
`#` стена, `.` улица, `,` пол дома, `D` дверь, `w` окно, `c` ящик, `C` высокий ящик, `A` спавн.
